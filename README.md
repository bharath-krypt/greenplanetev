# Green Planet Ev Spares — Landing Page

Modern landing page for an electric two-wheeler parts supplier (Green Planet Ev Spares).

## Features

- Hero with stats and CTAs
- Part finder (vehicle + category)
- Category grid (8 main categories)
- Product catalog with bulk pricing tiers
- Search modal (⌘ feel, Escape to close)
- Shopping cart with WhatsApp checkout
- Why us, testimonials, FAQ, contact form
- Floating WhatsApp button
- Dark theme, electric green accent, mobile responsive

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:5173

## Build

```bash
npm run build
npm run preview
```
